Pomodoro Timer & Theme Switcher
A simple browser-based productivity timer with a random background color generator built using vanilla JavaScript.

Features
25-Minute Countdown: Toggle start and pause for focus sessions.

Formatted Display: Automatic zero-padding for clean time formatting (MM:SS).

Dynamic Background: Generates a new hex color on demand to refresh the UI.

Zero Dependencies: Pure HTML, CSS, and plain JavaScript.

Setup & Usage
1.Open index.html in your web browser.

2.Click the timer button to start or pause the 25-minute countdown.

3.Click the color switcher button (#one) to generate a new background color.
